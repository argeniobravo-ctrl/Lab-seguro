=== CHECKLIST HACKING ETICO WEB - Dany ===

1. XSS (Cross Site Scripting)

Vulnerable: {{var | safe}} / innerHTML = userInput
Payloads: 
  <script>alert(1)</script>
  <img src=x onerror=alert(1)>
Fix: {{var}} (sin safe), escapar HTML, usar textContent no innerHTML

2. SQLi (SQL Injection)

Vulnerable: f"SELECT * FROM users WHERE id={id}"
Payloads:
  1 OR 1=1
  0 UNION SELECT 1,2,3
  ' OR '1'='1
Fix: query parametrizada -> WHERE id = ? , (id,)

3. LFI / Path Traversal

Vulnerable: open(f"paginas/{page}.txt")
Payloads:
  ../secreto
  ../../etc/passwd
  ..%2F..%2Fetc%2Fpasswd
Fix:
    - Bloquear si ".." in page or "/" in page
    - os.path.abspath(ruta).startswith(BASE)
    - Whitelist: solo permitir ["inicio","contacto"]
